# 诗库标签统一标准

对应优化文档“第五部分：陈誉文开发主线”第 1 项“诗库扩展与内容结构化”。本标准同时用于诗库批量导入和 `/poems/resolve` 核验后直接写入现有 `poems` 表。

## tags

- 2-5 项。
- 使用现代汉语中的核心名词、动作或概念。
- 优先描述全诗最重要的景物、行为、季节、节日、事件或情感。
- 不使用作者、朝代和非必要人物主语。
- 不直接复制古文词组或完整诗句片段。
- 禁止“古诗、诗词、优美、传统文化、好诗、儿童启蒙”等空泛标签。

## theme_tags

- 2-4 项。
- 必须直接复用 `tags` 中的 1-2 项。
- 再补充情感、意义、整体氛围或儿童学习方向。
- 不允许全部脱离核心标签重新造一套主题词。

## knowledge_tags

- 1-3 项。
- 只能从代码中的 `ALLOWED_KNOWLEDGE_TAGS` 枚举选择。
- 作者名、朝代、体裁、季节名和普通场景词不能写入 `knowledge_tags`。

## 年龄与难度

- `age_3_4` 必须对应 `3-4岁`。
- `age_5_7` 必须对应 `5-7岁`。
- `difficulty` 只能为 1、2、3。

## 工具

预检：

```powershell
python scripts/normalize_poem_tags.py
```

应用清洗：

```powershell
python scripts/normalize_poem_tags.py --apply
```

清洗脚本只根据诗词正文和已有元数据做确定性转换；不会凭空添加诗中不存在的季节、节日、人物关系或场景。清洗后仍需通过导入质量门禁才能进入数据库。
